About Nikinix

Nikinix is a work-in-progress, Unix-like operating system kernel developed from scratch for the x86_64 architecture. Built as an independent hobby project, Nikinix explores low-level system programming, kernel development, memory management, hardware interaction, and operating system design. It features its own kernel, virtual filesystem, RAM filesystem, system calls, interrupt handling, hardware support, and a basic userspace shell. Nikinix is constantly evolving, with new features and improvements being developed along the way.
